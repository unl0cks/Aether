Aether stops leaking memory during long sessions, and you can choose the font the game draws its
text with.

## The slowdown over a long session

AQW rebuilds its display list constantly. Every avatar that walks on screen, every effect, every
piece of interface that opens and closes adds and removes objects, and each of those additions and
removals dispatched four events whether or not a single script was listening for them.

Measured over fifteen minutes of ordinary play, that came to 2.82 million events, nearly all of them
delivered to nobody. Each one allocated an event object, walked the display list to find listeners
that did not exist, and left the result for the garbage collector.

Those events are now only built when something is actually listening for them. The events a script
does listen for still arrive exactly as before, in the same order and the same phases, so nothing
observable to the game has changed.

The same fifteen minutes now produces 2 events rather than 2.82 million. AVM2 object construction is
down 86 percent, allocation is down from roughly 935,000 to 800,000 per second, and memory growth
over the session is down 22 percent. Frame rate is unchanged.

## Choosing the font

AQW embeds the faces it draws its text with, so the game's own settings are the only way to change
them and they only reach part of the interface. Aether can now substitute a font of your choosing.

By default this covers chat and the names over characters' heads, which is the text you read while
playing. The menus, server list and buttons keep the game's own font. That scope is deliberate:
replacing every field in the game at once looks less like a font choice and more like something has
gone wrong.

If you do want all of it, there is a switch for that.

Eight faces are offered rather than everything installed on the machine, because most of a system
font list is symbol and CJK faces that draw AQW's Latin text as empty boxes. Courier New is asked
for at its bold weight, since its regular cut is far lighter than the faces the interface was drawn
around and reads as washed out against the art.

Changing it applies straight away. Text already on screen is redrawn rather than waiting for a
reload.

### Using it

Under Gameplay in the options window, which is F1 by default:

- **Font.** Default leaves the game's own choices alone.
- **Apply to all text.** Off by default. On, the chosen font replaces every text field in the game.

From the command line:

    --ui-font <arial|verdana|trebuchet_ms|georgia|times_new_roman|courier_new|consolas|comic_sans_ms>
    --ui-font-all-text
    --no-ui-font-all-text

### What it does not cover

Button labels such as Back, Save Room and Clear House are static text. Flash stores those as glyph
numbers pointing into one particular embedded font rather than as letters, so there is no text to
redraw in another face. They keep the game's font whatever is chosen.

Tahoma and Segoe UI are not offered. Both drew the server list as unreadable fragments, and an
option that is known to break somewhere is worse than one that is absent.
