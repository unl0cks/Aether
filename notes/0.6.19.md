Taunt's two auras look identical. This tells them apart.

## Focus and Reckless

Taunt applies Focus and Reckless together, and AQW draws both as the same white skull. The only
thing separating them is duration: Focus runs six seconds, Reckless ten. If you time a loop taunt,
Focus is the one you are watching, and picking it out of two identical icons mid fight is guesswork.

Focus can now be tinted so it is the one you can see at a glance. The icon keeps its own light and
shade either way; only the channels it is drawn through change. Nothing about the auras themselves
is altered, and nothing is hidden.

It matches on the aura's name, so it covers every class whose taunt applies Focus.

## Using it

Under Gameplay in the options window, which is F1 by default:

- **Show Focus (taunt) aura in different color.** Off by default, since this changes how the game
  looks rather than fixing something.
- **Colour.** Nine choices. Red is the default.

From the command line:

    --recolour-focus-aura
    --no-recolour-focus-aura
    --focus-aura-colour <red|orange|yellow|green|cyan|blue|indigo|pink|magenta>

The setting is saved, so it survives a restart.
